# XELATECH_SOPORTE_V2
Este es un sistema desarrollado en C# que simula las operaciones básicas
de un servicio técnico de equipo informático

Funciones del programa:
Xelatech Soporte permite registrar clientes, técnicos, equipos y repuestos, gestionoar solicitudes de servicio, asignar y atender trabajos y consultar
busquedas mediante busquedas, ordenamientos y reportes
El proyecto está organizado en clases que separan las entidades del sistema, la lógica de gestión, las validaciones y la interacción con el usuario.

- Funcionalidades principales
Gestión de clientes: registro, consulta y actualización de datos de contacto.
Gestión de técnicos: registro y consulta de técnicos, especialidades y disponibilidad para recibir trabajos.
Gestión de equipos: administración de laptops, equipos de escritorio e impresoras.
Gestión de solicitudes: creación, consulta, asignación, cambio de estado, historial y cancelación de solicitudes.
Diagnósticos y repuestos: registro de diagnósticos, acciones realizadas y repuestos utilizados en una solicitud.
Atención por prioridad: manejo de colas para solicitudes urgentes y normales.
Control de carga: seguimiento de la carga de trabajo de los técnicos durante la semana.
Búsquedas y ordenamientos: consulta de registros y organización de resultados por distintos criterios.
Reportes: información sobre solicitudes, técnicos, equipos, repuestos, ingresos y calificaciones.
Datos de prueba: generación de registros de ejemplo para facilitar la prueba del sistema.
Validaciones: comprobación de datos ingresados y manejo de errores de validación.

- Tecnologías utilizadas:
C#,
.NET 10,
Aplicación de consola,
Visual Studio,
Git y GitHub para el control de versiones

- Requisitos
Para abrir y ejecutar el proyecto se necesita .NET SDK 10.
Visual Studio con la carga de trabajo de desarrollo de .NET, o un editor compatible con proyectos .NET.
Git, si se desea clonar el repositorio.

- Cómo ejecutar el proyecto
Clonar el repositorio o descargar el proyecto,
Abrir XELATECH_SOPORTE_P2.csproj en Visual Studio,
Esperar a que Visual Studio restaure los componentes necesarios,
Compilar la solución,
Ejecutar el proyecto con F5 o mediante el comando:dotnet run
